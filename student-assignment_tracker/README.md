# 📚 Assignment Tracker CLI

A simple command-line Assignment Tracker built using Python.

This project allows students to keep track of assignments, view and mark them as completed.

## Features

-  Add new assignments
-  View all assignments
-  Mark assignments as completed
-  Exit the application

---

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
